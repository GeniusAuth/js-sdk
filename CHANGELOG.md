# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-24

### Added

- Browser-first OAuth 2.1 Authorization Code flow with PKCE.
- Popup and full-page redirect support.
- Callback validation and automatic pending authorization cleanup.
- TypeScript declarations with ESM and CommonJS distributions.
