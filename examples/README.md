# GeniusAuth JavaScript SDK examples

These framework-ready integration snippets use the published `@geniusauth/js` package. Replace `your_client_id` with a client registered in the [GeniusAuth dashboard](https://docs.geniusauth.com), and register the shown redirect URI.

| Directory    | Host application                   |
| ------------ | ---------------------------------- |
| `vanilla-js` | Any browser TypeScript application |
| `react`      | React application                  |
| `vue`        | Vue application                    |
| `nextjs`     | Next.js App Router application     |
| `nuxt`       | Nuxt application                   |

Use the snippets inside the matching framework starter. The authorization-code exchange belongs in your server-side callback endpoint; never put a client secret in client code.
