# Contributing to GeniusAuth JavaScript SDK

Thanks for contributing. Read the [documentation](https://docs.geniusauth.com) before opening an issue or pull request.

## Development

```bash
npm ci
npm run check
```

## Pull requests

- Use [Conventional Commits](https://www.conventionalcommits.org/).
- Keep pull requests focused and covered by tests.
- Run `npm run check` before requesting review.
- Do not include credentials, tokens, or private keys.
